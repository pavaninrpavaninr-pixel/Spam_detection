# 📩 Spam Detection System - AI Powered

An intelligent Machine Learning web app that detects whether a message/email is SPAM or NOT SPAM.

🚀 **Live Demo:** https://spam-detection-4frj.onrender.com

### ✨ Features
- Real-time Spam Detection using NLP
- Clean & Responsive Web UI (Flask)
- ML Model trained with Scikit-Learn
- Deployed on Render

### 🛠️ Tech Stack
- Python
- Scikit-Learn, NLTK, Numpy
- Flask
- HTML, CSS
- Render for Deployment

### 🎯 How It Works
1. User enters a message
2. Text is cleaned & vectorized (TF-IDF)
3. Trained ML model predicts Spam/Ham
4. Result shown instantly
